A water delivery ordering site for a hostel/campus community — one index.html file, powered by Supabase. No framework, no build step, no server to host.

🚰 For customers
Sign up & log in
Order a new bottle, a refill, or both
Pick a one-time, recurring, or custom delivery schedule
Upload a payment screenshot & track order status live
🛠️ For the team
📦 Manage & update every order in real time
👥 Track customers, including walk-ins with no account
📊 Revenue & profit analytics at a glance
🔔 Live activity feed — abandoned checkouts, overdue refills, and more
💬 One-tap WhatsApp messages to customers
🤝 An internal profit-sharing ledger for the team's own use
⚙️ Site settings, including maintenance mode
⚡ Under the hood

Supabase handles auth, the database, real-time sync, file storage, and email — all with row-level security baked in.
